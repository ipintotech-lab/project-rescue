# RescueMap אתר הדגמה

אתר עצמאי בעברית עם תצלומי הדגמה לפני ואחרי, השוואה, מבנים, דיווחים, משימות ועורך תרחיש. כל המידע מדומה ואינו מיועד לפעילות חילוץ אמיתית.

## הרצה מקומית

נדרש Node.js 22 ומעלה. אין חבילות להתקנה.

```bash
npm start
```

פתחו http://localhost:3000. בדיקה בסיסית: `npm run check`.

## הרצה ב Railway

1. חלצו את הקובץ והעלו את תוכנו למאגר GitHub שלכם. package.json ו Dockerfile צריכים להיות בשורש המאגר.
2. ב Railway צרו פרויקט ובחרו Deploy from GitHub repo ואת המאגר.
3. ה Dockerfile מגדיר את הבנייה. פקודת ההפעלה היא `node server.mjs` או `npm start`.
4. השרת מאזין ב 0.0.0.0 ומשתמש ב PORT ש Railway מספק. אין להגדיר פורט קבוע.
5. ב Settings ואז Networking בחרו Generate Domain.
6. בדקו את האתר ואת הנתיב /health. שינוי בקוד והעלאתו לענף המחובר מאפשרים פרסום גרסה נוספת לפי הגדרות הפרויקט.

railway.json כולל healthcheck ופקודת הפעלה. לא בוצעה פריסה לחשבון Railway בפועל. תיעוד: https://docs.railway.com/guides/express ו https://docs.railway.com/deployments/start-command

## מה עורכים

- dist/index.html — מבנה המסכים ותוכן קבוע.
- dist/style.css — צבעים, מידות, עיצוב ופריסת מובייל.
- dist/app.js — בחירת מבנים, השוואה, דיווחים ועריכה.
- dist/scenario.json — ברירות מחדל של האירוע, המבנים ומיקומי הסימונים באחוזים.
- dist/assets/aerial-pair.png — דימוי AI משולב: חצי שמאל לפני, חצי ימין אחרי. CSS מציג כל חצי כשכבה עצמאית.
- server.mjs — שרת קבצים קטן ונתיב בריאות.

כדי לשנות במהירות ללא קוד: פתחו עריכת תרחיש, שנו כותרת ומידע על מבנים ושמרו. ייצוא JSON מוריד קובץ שאפשר להעתיק אל dist/scenario.json לפרסום לכל המשתמשים. שינוי ברירת מחדל אינו דורס תרחיש שכבר נשמר בדפדפן; לחצו אפס נתוני הדגמה כדי לטעון מחדש את ברירת המחדל מהשרת.

כפתורי החלפת צילום מאפשרים בחירת קובץ מקומי. התמונות אינן מועלות לשרת ואינן נשמרות לאחר רענון. כדי לפרסם תמונות קבועות, שמרו אותן בתיקיית assets ושנו את הגדרות הרקע ב CSS לשתי כתובות נפרדות עם background-size:100% 100%. יש לוודא זכויות שימוש.

## שמירת מידע ומגבלות

תרחיש, דיווחים ומשימות נשמרים ב localStorage בדפדפן וממשיכים אחרי רענון. זו אינה שמירה משותפת בין משתמשים ואין שרת דיווחים, חשבונות, הרשאות או חיבור לציוד חי. מצב ניתוק הוא סימולציה ולא יישום offline מלא. יש להוסיף בסיס נתונים, אימות וסנכרון לפני פיילוט עם מידע אמיתי. אין להזין מידע אישי או מבצעי רגיש באתר ההדגמה.

דיווחים חדשים אינם משנים ספירת אנשים באופן אוטומטי. המערכת מציגה שהם ממתינים לבדיקת חפיפה; אין עדיין ממשק למיזוג דיווחים. רשימת המבנים ממוינת לפי ספירה מדווחת להדגמת ההשוואה בלבד. אין אלגוריתם תעדוף מבצעי מאושר.

התצלומים נוצרו ב AI ואינם צילום לוויין או רחפן אמיתי. השוואתם אינה רישום גאוגרפי מדויק, סימוני המבנים מקורבים, נתוני קומות ודירות הם נתוני תרחיש ואינם תוצאה של ניתוח תמונה. ממשק טופוגרפיה מדיד, מפות GIS ותכנון נתיבים אינם ממומשים.

## יצירת נכס ההדגמה

נעשה שימוש במחולל התמונות המובנה. תקציר פרומפט: זוג תמונות אוויריות אנכיות של שכונת מגורים ים תיכונית דמיונית, אותה נקודת מבט לפני רעידת אדמה ואחריה, בניין גדול קרוס ובניין קטן עם קריסה חלקית, ללא אנשים, פציעות או טקסט. התמונה משמשת להמחשת הממשק בלבד.
